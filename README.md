# Invitación 32 años

Invitación web estática (GitHub Pages desde `main`, raíz). Sin build.

- `script.js` — bloque `EVENTO` al inicio con todos los textos editables (marcados `TODO`).
- `index.html` — `<title>` y meta Open Graph (lo que muestra WhatsApp al compartir): editar a mano.
- `invitacion.ics` — evento para Apple Calendar/Outlook (TZID America/Santiago, recordatorio 3 h antes): editar a mano si cambian nombre, fecha u hora.
- `og-image.jpg` — imagen de vista previa (1200×630).
